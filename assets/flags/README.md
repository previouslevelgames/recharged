# Flags

The flags beside players' names in the Recharged Game Menu and the launcher
(a player's country, which the profile server finds from where they connect,
or the one they chose).

`flags.png` holds the flag of every ISO 3166-1 country, 32x24 pixels each,
16 to a row, in the order of their two letters, which
`src/overlay/flag_countries.inc` lists with each one's English name. Both
come from
[flag-icons](https://github.com/lipis/flag-icons) 7.2.3 by Panayiotis
Lipiridis, under the MIT license (`LICENSE-flag-icons`), made with
`tools/flag_atlas.py`.
